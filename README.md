# CivicCompass

A civic-tech web application that helps users understand political information through manifesto analysis, voter matching, policy translation, and an interactive chatbot.

## Features

- Manifesto analysis
- Voter preference matching
- Plain-language policy translation
- Interactive chatbot interface
- Responsive React UI

## Tech stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React icons

## Getting started

```bash
git clone https://github.com/AnshRajRath/pro_cc.git
cd pro_cc
npm install
npm run dev
```

## Project idea

CivicCompass is designed to make dense political and policy information easier to explore. Instead of forcing users to read long-form manifestos or policy text directly, the interface breaks the experience into analysis, comparison, translation, and conversational assistance.
